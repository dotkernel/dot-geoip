# Installation

## Requirements

- PHP 8.3, 8.4, 8.5 or 8.6
- The PHP extensions `curl` and `zlib`

## Install the package

Install `dotkernel/dot-geoip` by executing the following Composer command:

```shell
composer require dotkernel/dot-geoip
```

If your application does not use [dotkernel/dot-cli](https://github.com/dotkernel/dot-cli) yet, this command also installs it.
Read its documentation to learn how to run console commands.

To upgrade from version 3, read [Upgrading](upgrading.md).
